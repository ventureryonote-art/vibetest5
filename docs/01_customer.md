## 今回の題材の絞り込み

**「体験授業の問い合わせ台帳」に絞ります。**
理由: 問い合わせの「受け取り口」（LINE連携・HPの申込フォーム）は**お客さん側からの入力**にあたり、今回は作らないためです。
今回作るのは、**自分（教室側）が問い合わせを1件ずつ登録して、今日返信すべき人を探して、状態を変える**画面だけです。

> 受け取り口の自動化は第2〜3回で扱います。まず「返信漏れが消える台帳」が成立するかを確かめます。

- **その人に、他の人より会いやすい理由**: 🔮 本人がその教室に通っている／通わせている、または知人が講師をしている等、**すでに顔が通っている1軒がある**可能性が高い

## 2. 解く課題

- **困っていること**: 体験授業の問い合わせがLINEと電話とHPからバラバラに来て、返信漏れが月2〜3件起きている（← 本人の言葉）
- **今その人はどうやっているか**:
  🔮 LINEは公式アカウントのトーク画面、電話は手元のメモ用紙、HPは問い合わせメールと、**3か所を別々に見て回っている。**
  返信済みかどうかは「トークが既読になっているか」「メモに丸が付いているか」で判断しており、**一覧になっている場所がどこにもない**と思われる。
  → 確かめ方: 「昨日来た問い合わせは、今どこを見れば全部わかりますか？」
- **かかっている時間 / 費用**:
  🔮 3か所を見て回る確認が**1日10〜15分**（月に約5時間）。問い合わせは**月30〜50件**、1件の対応に5〜10分。
  🔮 これに加えて、**返信漏れ月2〜3件の逸失**が大きい。体験に来れば入会する割合が高い業種のため、月2〜3件の取りこぼしは**年間で数十万円〜100万円規模**の売上機会に相当する可能性がある。
  → 確かめ方: 「体験に来た方のうち、どれくらいが入会されますか？」「月謝はおいくらですか？」
- **なぜ今まで誰も解決していないのか**:
  - [x] **データが散っている** ← これが主因と思われる
  - [ ] 市場が小さい　[ ] 量が多すぎる　[ ] 判断が非定型　[ ] n=1すぎる

  🔮 理由: LINE・電話・HPフォームは**それぞれのプラットフォームの中に閉じている**ため、横断して1つの一覧にする標準的なやり方が存在しない。
  既存の塾管理システムは**入会後の生徒管理（月謝・出欠・成績）**が主戦場で、**入会前の問い合わせは各教室の手癖**に任されたままになっていると思われる。
  → 確かめ方: 「今お使いの塾システムに、まだ入会していない人を登録する場所はありますか？」

  **「今日返信すべき人」が、画面を開いた瞬間に一目で分かること。**
  （＝返信漏れ月2〜3件が、月0件になる）

## 3. やらないこと

- **お客さん側からの申し込みフォームは作らない**（今回は教室側が手で登録する台帳に絞る）
- **LINE・メールとの自動連携、自動返信は作らない**（返信は今まで通り本人が各アプリで行う）
- **入会後の生徒管理（月謝・出欠・成績・請求）は作らない**（問い合わせ〜体験までの1本に絞る）

> この3つは「作りたくなるが、今回はやらない」ものです。
> 特に1つ目を入れた瞬間に、ログインと通知とセキュリティが必要になり、25分では終わりません。

## 4. 出口 ── 作る前に確認する3つ

### ① 誰が払うか

- **払う人**: 🔮 **教室のオーナー本人。**小規模教室では「使う人」と「払う人」が同一人物である可能性が高い。
  ただし**フランチャイズ加盟教室の場合は本部が決裁**し、加盟店が勝手にツールを入れられないケースがある。
  → 確かめ方: 「新しいツールを入れるとき、ご自身で決められますか？ 本部の承認が要りますか？」
- **その相手は、この種のものに金を出す商習慣があるか**:
  🔮 **ある可能性が高い。**塾管理システム、LINE公式アカウントの有料プラン、予約システムなどに**月数千円〜2万円**を払う習慣がすでにある業種と思われる。
  ただし個人教室は価格感度が高く、**月3,000円前後が心理的な上限**になる可能性がある。
  → 確かめ方: 「今、教室の運営で毎月払っているソフトやサービスはありますか？ いくらですか？」

### ② どう届くか

- **その市場が「実際に使っている」経路**:
  🔮 **下の経路（紹介・口コミ・業界内の直接接触）**が本命と思われる。
  具体的には、① 教室オーナー同士の横のつながり（地域の私塾協会、同業の勉強会、フランチャイズ加盟店の交流会）、② 教材会社・教室コンサル・税理士など**すでに教室に出入りしている人からの紹介**。
  🔮 **上の経路（検索・広告）は不利。**「塾 管理システム」は大手が広告を出し切っており、獲得コストで勝てないと思われる。
  → 確かめ方: 「今お使いの〇〇（既存ツール）は、どこで知りましたか？ 誰かに勧められましたか？」

> ⚠ **ここが 🔮 のままなのが、今回いちばん危険です。**
> 経路を外すと、いくら良いものを作っても届きません。**量では取り返せません。**

### ③ 受け取れるか（決済・審査・規制）

- **確認したか**: **はい**
- **確認した内容**:
  **要審査・禁止業種には該当しない。**教育・スクール向けの業務ツールであり、投資・金融／医療・健康／サプリ・美容の効能／法律相談／暗号資産／ギャンブル／アダルト／情報商材のいずれにも当たらない。
  ただし**個人情報の扱いには注意が必要**。問い合わせ者の氏名・連絡先は個人情報であり、多くは**未成年の保護者**からの問い合わせ。
  → 今回の作りでは **`localStorage`（その端末のブラウザの中だけ）に保存し、外部のサーバーには一切送らない**。この設計であれば、今回の範囲で問題は生じない。
  → ⚠ 将来サーバーに保存する形にする場合は、保管場所と削除方法の説明が必要になります。

### 競合には必ず「DIY」を入れる

- **既存の競合**:
  🔮 ① 塾向け管理システム（Comiru、Kizuku、テラコヤプラス系など）＝**入会後が主戦場**で、問い合わせ段階は手薄
  🔮 ② LINE公式アカウントのタグ・ノート機能＝**LINE以外の経路が入らない**
  🔮 ③ Googleスプレッドシート／Excel＝**実は最強の競合**。無料で、すでに使える
  🔮 ④ 紙のノート・付箋
- **DIY競合**（顧客が自分でAIに作らせる）:
  🔮 オーナー自身が ChatGPT に「問い合わせ管理のスプレッドシートを作って」と頼み、関数やGASを書かせる。
  **これは今日すでに可能で、無料。**「表を作る」だけなら、こちらに勝ち目はないと考えたほうが安全。
- **選ばれる理由**:
  🔮 **【時間】**＋**【埋め込み】**の2つ。機能では書かない。
  - **時間**: 3か所を見て回る1日10〜15分の確認が、**画面1つを開く動作**に置き換わる。返信漏れ月2〜3件が0になる。
  - **埋め込み**: **開校前の5分**という、すでに存在する動作の中に入り込む。スプレッドシートは「開く理由」を作れないが、「今日返信すべき人だけが出ている画面」は開く理由がある。
  → 確かめ方: 「毎朝、教室を開ける前に必ず見るものは何ですか？」

> ⚠ **【データ】と【責任】はこの題材では取れません。**
> 自分しか持っていない情報はなく、返信結果に責任も取れないためです。
> **取れるのは【時間】と【埋め込み】だけ**と考えて設計してください。
